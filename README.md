# MeeNaradha

MeeNaradha is a Telugu-first bilingual entertainment discovery and audience platform.

## V1 scope
- Telugu / English publishing
- News articles
- Movies and celebrity profiles
- Image galleries
- Video Hub: trailers, teasers, promos, events and interviews
- Short films
- OTT updates
- Reviews and box-office content
- Top 10 / trending, polls and contests
- Movie Pulse audience reactions
- Editorial CMS

## Planned stack
Next.js + TypeScript + Tailwind CSS, Supabase, Vercel, GitHub.

## V1 principle
New product ideas go to the future backlog unless essential for launch.
